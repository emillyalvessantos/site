1. Componentes Internos

1.1.1 CPU

A CPU (Unidade Central de Processamento) é o cérebro do computador, responsável por executar instruções e processar dados.

1.1.2 Armazenamento

Os dispositivos de armazenamento, como HDDs e SSDs, guardam dados e programas para serem acessados pelo computador.

1.1.3 Memória

A memória RAM armazena temporariamente os dados necessários para a execução de processos no computador.

1.1.4 Fonte de alimentação

A fonte de alimentação converte a energia da tomada para níveis utilizáveis pelo computador.

1.2 Componentes Externos

1.2.1 Teclado

O teclado é um dispositivo de entrada usado para digitar informações no computador.

1.2.2 Monitor de vídeo

O monitor exibe as informações processadas pelo computador, permitindo a interação do usuário.

1.2.3 Mouse

O mouse é um dispositivo de entrada que permite controlar o cursor na tela do computador.

1.3 Interfaces de Entrada e Saída

1.3.1 Interfaces sem fio

As interfaces sem fio incluem tecnologias como Bluetooth e Wi-Fi para conectar dispositivos sem cabos.

1.3.6 USB

A interface USB permite a conexão de periféricos como teclados, mouses e dispositivos de armazenamento externo.

2. Grandezas Elétricas

2.1 Potência elétrica

A potência elétrica mede a taxa de conversão de energia elétrica em outros tipos de energia, como térmica ou mecânica.

2.2 Tensão elétrica

A tensão elétrica, medida em volts, representa a diferença de potencial entre dois pontos de um circuito.

2.3 Corrente elétrica

A corrente elétrica é o fluxo ordenado de elétrons em um circuito, medido em amperes.
